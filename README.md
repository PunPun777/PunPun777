### 🔱 [Heimdall-CLI](https://github.com/AdityaDotEnv/Heimdall-CLI) &nbsp;·&nbsp; *team project*
**Autonomous, local-first terminal AI agent for SOC triage and forensic investigation**

Ingests Wazuh alerts and network telemetry, classifies anomalies with a **CNN** (CIC-IDS2017) and **LSTM** (NSL-KDD), explains them with **SHAP / LIME**, reasons through local **Ollama LLMs** with dual-model hallucination arbitration, and runs memory and disk forensics, all from your terminal. Orchestrated as a resumable **LangGraph** state machine with SQLite checkpoints. Nothing leaves the machine.

📊 CNN ROC-AUC **0.9999** on held-out CIC-IDS2017 &nbsp;•&nbsp; LSTM ROC-AUC **0.9503** on KDDTest+ &nbsp;•&nbsp; every claim traced to a result artifact
